# Formatting document service
Програма дозволяє перенести форматування з файлу-зразка в потрібний документ Word.
# Інструкція застосування програми:
1. Завантажити файли formatting-document, Sample.docx та Target.docx на комп’ютер та помістити їх в одну папку.
2. Скопіювати код із файлу formatting-document в модуль Microsoft Visual Basic for Applications у новий документ Word.
3. Створити дві кнопки на панелі швидкого доступу створеного документа Word, які б відповідали за дві процедури коду з файлу formatting-document.
4. Натиснути на першу кнопку та вибрати файл Sample.docx.
5. Натиснути Ok у вікні, що з’явиться.
6. Натиснути на другу кнопку та вибрати файл Target.docx.
7. Натиснути Ok у вікні, що з’явиться.


# Формат документа-зразка, який переноситься в цільовий документ
# Параметри сторінки:
1. Поля: зліва 2,5 см, справа 1 см, верхнє 2 см, нижнє 2 см.
2. Верхній колонтитул: 4 см.
3. Нижній колонтитул: 1,4 см.

1. Заголовок 1: Times New Roman, 14, жирний, вирівнювання за шириною, перший рядок 1,25 см, міжрядковий інтервал 1,5, заборона нависаючих рядків, не відривати від наступного, не розривати абзац, заборонити автоматичний перенос слів.
